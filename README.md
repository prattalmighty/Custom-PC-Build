# Custom PC Build

## Overview

In 2020, I built a custom desktop computer for photo editing and gaming.

The project began with defining the intended use and budget, then researching compatible components using PCPartPicker. With guidance from an experienced PC builder, I selected the components and assembled the system.

This was my first experience building a PC from individual components and gave me practical exposure to hardware compatibility, component installation, system assembly, and initial configuration.

## Objectives

- Build a desktop suitable for photo editing and gaming
- Stay within a defined budget
- Learn how individual PC components work together
- Gain hands-on experience assembling and configuring a computer
